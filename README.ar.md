# جولان كلينر برو

[English](README.md)

معاينة Android لإدارة الملفات والتخزين **0.11.1 / الرمز 14**، الحزمة `app.golan.cleaner.pro`؛ الحد الأدنى Android 9/API 28، والبناء والاستهداف SDK 36. يدعم العربية والإنجليزية واتجاهي الكتابة ووضع النظام الفاتح والداكن وهوية مكنسة GOLAN. ملف APK المسلّم موقع بمفتاح debug.

## الوظائف

- **تنظيف:** تحليل تخزين ضمن نطاق واضح، واقتراحات بعد المراجعة، واستعادة خاصة محدودة، وتنظيف تلقائي بتفعيل صريح.
- **ملفات:** تصفح المجلدات المتاحة وبحث وفرز المجلد الحالي والتحديد والفتح والمشاركة والتفاصيل وإنشاء مجلد وإعادة التسمية ونسخ ونقل وحذف الملفات بعد المراجعة حيث تسمح واجهة التخزين والأذونات.
- **محفوظات:** حفظ نصوص وصور الإشعارات المستقبلية المتاحة لمحادثات يحددها المستخدم، في تخزين خاص مشفر مع تشخيص الأذونات والوسائط.
- معلومات الجهاز وأذونات التطبيقات المرئية وإزالة التطبيقات بتأكيد Android وروابط إعدادات التخزين المؤقت والإعدادات وحول.

## التثبيت والأذونات

نزّل APK من مرفقات الإصدار وقارن بصمته مع `SHA256SUMS.txt`. اسمح بالتثبيت للتطبيق الذي يفتحه ثم ثبّت. امنح الوصول يدوياً فقط للمجلدات التي تريد استعمالها. يستخدم Android 9 أذونات التخزين، وقد يتطلب Android 10 اختيار مجلد، ويتاح الوصول الاختياري لجميع الملفات في Android 11+. الوصول الواسع وحده لا يفعّل التنظيف التلقائي. أرشيف الإشعارات يحتاج إفصاحاً منفصلاً ومنح الوصول يدوياً واختيار المحادثات والنصوص والصور.

يتطلب التحديث توقيعاً متوافقاً مع النسخة الموجودة. إزالة التطبيق أو مسح بياناته يمحو نسخ الاستعادة وأرشيف الإشعارات الخاصين. احفظ الملفات المهمة في مكان آخر ولا تعتبر الاستعادة الخاصة نسخة احتياطية مستقلة.

## المصدر الكامل والبناء

نزّل `golan-cleaner-pro-0.11.1-source.zip` من مرفقات الإصدار و**فك ضغطه قبل البناء**. يحتوي مصدر `app` و`core` المنقح الكامل والاختبارات القائمة والموارد وGradle wrapper. عرض README فقط لا يحتوي المشروع الكامل.

ثبّت JDK 17 لتشغيل Gradle وسلسلة أدوات JDK 21 وAndroid SDK 36 وأدوات بناء متوافقة. اضبط Java وSDK محلياً أو أنشئ `local.properties` غير متعقب مع `sdk.dir`. من جذر الأرشيف:

```powershell
.\gradlew.bat :app:assembleDebug
```

في Linux/macOS استخدم `chmod +x gradlew && ./gradlew :app:assembleDebug`. الناتج المعتاد `app/build/outputs/apk/debug/app-debug.apk`. يلزم اتصال لتنزيل Gradle والاعتماديات. قد يختلف مفتاح debug المحلي عن الملف المسلّم. احتُفظ بالاختبارات ولم يُنفذ بناء أو اختبار أو إجراء هاتفي جديد أثناء التجهيز.

## الحدود العملية

التنظيف التلقائي متوقف افتراضياً. يتطلب سياسة صريحة لما يصل إلى ثمانية مجلدات محددة ومحتويات مؤقتة قديمة معتمدة، وعمر 14 يوماً على الأقل، وملاحظتين ثابتتين بفاصل 30 ثانية على الأقل وفحصاً حديثاً للأذونات وهوية الملف. حد الجولة 20 ملفاً و16 MiB وميزانية تعاونية 60 ثانية، وليست مهلة قاطعة لعمليات تخزين متوقفة. الجدولة اليومية اختيارية وغير دقيقة الموعد.

ينشئ الحذف بعد المراجعة نسخة استعادة خاصة متحققة وسجلاً قبل إزالة الأصل. الحد 100 ملف و256 MiB للملف، وميزانية الاستعادة المشتركة 1 GiB مع احتياطي 16 MiB ودون تفريغ تلقائي. تستعيد الملفات باسم جديد. تستهلك النسخ مساحة حتى حذفها يدوياً، وحجم النسخ لا يساوي تلقائياً المساحة المحررة. عرض المجلد محدود بـ2000 عنصر مباشر مع توضيح النتائج الناقصة. لا يوجد وعد بتعديل المجلدات تكرارياً أو الكتابة فوق الملفات أو الوصول غير المحدود للمجلدات الخاصة أو النظام أو Android/data.

الأرشفة للمحادثات المختارة والإشعارات المستقبلية المؤهلة فقط. صور JPEG/PNG/WebP تحتاج URI متاحاً وإذن قراءة حاضراً، وقد تكون الصورة مصغّرة. الحد 8 MiB للصورة و128 MiB لحجوزات ملفات الصور الخاصة. **التقاط وتنزيل الفيديو غير منفذ.** عدادات MP4 والفيديو تشخيص للقدرات وليست وظيفة حفظ فيديو. لا يمنع التطبيق حذف المرسل ولا يستعيد محتوى قديماً لم يره. لا يطلب الإنترنت أو root أو خدمة Accessibility للتنظيف.

تسجل نقطة 0.11.1 السابقة نجاح 729 اختباراً ضمن 71 مجموعة، دون فشل أو أخطاء Lint ومع 51 تحذيراً، وفحص تثبيت وتشغيل محدود على Motorola. هذه نتائج سابقة؛ قبول صور وفيديو تطبيقات المراسلة وكل الأجهزة وعمليات الملفات غير مثبت بالكامل. إعداد التخزين المشترك والمجلدات التلقائية على Motorola يعتمد على منح الوصول.
